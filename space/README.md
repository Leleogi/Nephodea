# Nephodea

Upload a photo of the sky and find out which clouds it shows. The model runs in your browser, so your photo is never uploaded.

It also finds the sky, marks the clouds and classifies the biggest cloud areas one by one.

Source code: https://github.com/Leleogi/nephodea
